Drop a TerraFirmaCraft NeoForge 1.21.1 jar in this directory to build against it.

TerraFirmaCraft is not published to a public Maven repository, so the build needs to find it either here or via
CurseForge (see `tfcCurseFileId` in `gradle.properties`). A jar in this directory always takes priority.

The jar itself is gitignored - it is not ours to redistribute.
